# Sixfold Recoil — private beta delivery

**Archived after the 2026-09-07 owner playtest.** Klaus rejected the current concept; the game is parked. This file preserves the local delivery record. See [STATUS.md](STATUS.md) for the current decision.

The owner authorized one local playable level. The self-contained HTML in `build/` is the playtest artifact; [BUILD.md](BUILD.md) records reproduction and [QA.md](QA.md) records verification. This is not a public release candidate.

No storefront, live price, marketing campaign, public deployment or purchase has been authorized or performed. The name remains provisional. The delivered experiment omitted full-game progression. Human playtesting has now produced negative feedback; physical controller coverage and speaker listening were not independently verified.

All included visual/audio material is original code with origins in [assets/manifest.csv](assets/manifest.csv). No third-party recordings, fonts or downloaded assets are bundled. A repository distribution license has not been selected by this prototype task.

The owner playtest led to parking this concept and researching substantially richer alternatives. Any later release work needs its own actual package and current platform requirements.
