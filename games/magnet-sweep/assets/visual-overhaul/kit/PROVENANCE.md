# Original machined salvage kit

Created in Blender by scripts/GenerateVisualKit.py for the owner-requested visual overhaul, 2026-09-13. No imported geometry, purchased assets or third-party visual references. Physical holes, bevels, gear teeth, laminations, fasteners and housings are authored as actual geometry; meshes have weighted normals, UVs and named material slots. Runtime fits their measured bounds to existing visual envelopes and disables engine collision, leaving the gameplay simulation unchanged.

Source Blender file and generator are retained. The mesh-report.json lists measured dimensions and triangle counts. Original project assets; no external attribution is required. The repository's overall distribution license remains unset.
