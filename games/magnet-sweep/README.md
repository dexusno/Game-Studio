# Magnet Sweep

**Parked project, 14 September 2026.** The complete redesign is now the independent [Scrap Combat game](../overkill-foundry/STATUS.md), public title pending. Continue redesign work there. This directory preserves the old Magnet Sweep implementation and historical records; it is not the new game's codebase.

Working title. Klaus selected the magnet game as the first experiment and requested three designers in direct debate, a professional production planner and a gameplay critic. Development timeline is explicitly not a design constraint. No engine project or playable build exists.

**Sweep a satisfying haul, aim a pull that breaks linked scrap loose, and forge a magnet that can do more.** The revised concept is untimed, retains earned improvements and offers fresh arrangements with the complete rig. Its gameplay and replay promises remain to be tested.
