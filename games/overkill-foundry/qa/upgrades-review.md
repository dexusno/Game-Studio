# P08 independent review — bounded pass

The final captured candidate passes **36 core groups and 15 production campaign groups**, including **8 actual process exits** across nested upgrade transactions. All seven issues recorded below are repaired and independently rechecked. No open defect remains in this finite batch. This does **not** close whole-P08 acceptance: two known haul-composition cases remain deliberately unavailable, and this review does not establish functional coverage of every eligible effect.

Owned files are `qa/upgrades/` and this report. The reviewer did not edit production. Acceptance sources are [P08 and the runtime matrix](../design/MVP-IMPLEMENTATION-PLAN.md), [upgrade rules](../design/UPGRADE-SYSTEM.md), [timing and persistence](../design/TIMING-AND-PERSISTENCE.md), recipe rows, and the exact upgrade JSON records. [Source expectations](upgrades/expectations.md) were prepared before the first compile. The independent [raw-field oracle](upgrades/source_oracle.py) confirms the exact **152 eligible / 127 ordinary / 25 Mayor** manifest sets; [recorded source contracts](upgrades/source-expectations.json) are structural and expectation evidence, not runtime acceptance of all those IDs.

## Coverage limits and review corrections

- **Known unavailable behavior:** final `upgrade_effects.inl:168–171` explicitly rejects a first-haul composition with more than 3 base units removed or a UGS-141 +2 voucher. The author identifies the stacked -4/-6 composition and voucher composition as awaiting the owner decision. This review inspected that guard but did not execute those cases or clear them for P08 acceptance.
- No independent semantic pass over all 152 IDs or all combinations. Registration, the source oracle, and the author's broader assertion totals do not substitute for that pass. Route-specific reveal/replacement/Survey behavior was outside this P08 batch. The latest author-added UGS-015 attachment-copy and UGS-038 lethal-sacrifice variations were not new independent probes here; only the stated U05/U34 boundaries were run on the final code.
- Arena setup deliberately constrains state. Campaign probes inject finite shop stock, sufficient Credits, memory capacity/exhaustion, and terminal 1000-damage Ammo to reach transaction boundaries. Mystery fixtures advance route state to the selected encounter. C-U15 clears initial memory but earns both entitlements through real combat completion; no entitlement or counter callback is substituted. This is not a balanced ordinary-city playthrough.
- The raw oracle excluded proposed UGS-027/043/059 before execution because they begin in city 2. UGS-067's real rescue is also outside this pool; no eligible new death rescue was found. The old scalar rescue fixture is not counted as P08 evidence.
- Initial U26 expected UGS-032 selection inside the core choice list; its API delegates a saved `CopyRecipe` request. The probe was corrected, and production candidate filtering was tested in C-U02/04. The initial [24/28 log](upgrades/evidence/initial-results.txt) includes that QA error as well as U-F01, U-F02 and U-A01; it must not be read as four game defects. An initial campaign fixture also used a nonexistent Mayor ID; it was corrected to source-eligible MY1-05 before the archived adapter results.
- **Not run:** packaged executable, graphical startup/input/focus/exit, audio, rendering, performance, full city economy, human comprehension/fun, balance or owner visual approval. No human playtest observations were collected. Serialization/Continue and native process startup/exit were exercised only through the typed native tests described above.
