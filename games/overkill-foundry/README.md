# Overkill Foundry

An independent turn-based roguelike about mercenaries forging powerful shots and shields from robot scrap while defending fortified cities.

Start with [STATUS.md](STATUS.md), then the [design plan](design/REDESIGN-PLAN.md), [606-recipe catalogue](design/RECIPE-CATALOGUE.md) and [style anchor](design/art%20anchor.png). The owner selected the title on 14 September 2026 after reviewing the [naming study and conflict screen](design/NAMING-STUDY.md).

This game was separated from [Magnet Sweep](../magnet-sweep/STATUS.md) on 14 September 2026 at the owner's request. Its design, decisions and art references carry forward; gameplay will be implemented afresh. No old gameplay code, engine project, saves, binaries or build evidence were transferred. Preserved concept illustrations and the Blender camera study are design references, not game screens or a playable build.

The planned platform is Windows, using Unreal unless the owner later changes that direction. No engine project exists yet. Next work is the remaining design Q&A before defining an implementation slice.
