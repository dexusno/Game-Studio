# Source and rights

Created 2026-09-10 by Game Studio with OpenAI Codex for Dreambound's authorized environment expansion. All twelve meshes and five texture pairs are original project-authored procedural work. No downloaded art, external photographs, extracted game assets or third-party texture libraries were used. Existing project-owned UV repair and FBX import helpers are reused. There is no third-party attribution requirement for these assets; the repository's project distribution/license decision still governs its own original work.

Reproducible creation source: `scripts/create_living_world.py`. Source mesh hashes, dimensions, triangle/vertex counts, material slots, two UV channels, vertex-mask meanings and placement contracts are recorded in `asset-metadata.json`. The FBXs have no collision hulls. `materials.json` records the complete original material palette and surface/motion settings. `Living_World.blend` is the editable source gallery. `manifest-rows.csv` contains exact rows for the integration owner's shared `assets/manifest.csv`; this worker does not write the shared manifest.

Kena and Horizon were supplied by the integration owner as quality references for layered organic shapes, habitat grouping and environmental history. No reference-game geometry, characters, textures or distinctive ornament was reproduced. The courtyard's existing original visual language remains the basis of this supporting set.

The large-prop revision adds a continuous smoothed woody union, overlapping bark plates, explicit end-grain rings, rounded fan-fungus rims/gills, original 2K surface fields and normal detail, weathering masks, ceramic mineral deposits and modeled edge wear. These are program-authored Blender geometry/materials rather than an AI image claimed to be playable geometry.

`living-world-spring-source.png` and `living-world-ruin-source.png` are labelled source-art previews made with Blender CPU rendering. They are not store screenshots or actual game evidence. Their larger insect scale is for source inspection; runtime uses smaller habitat-scale placements. The final engine import report is written to ignored `unreal/Saved/LivingWorld/import.json`; `import-report.json` preserves the completed 2026-09-10 import evidence: Editor exit 0, twelve meshes, sixteen materials, ten textures, zero warnings. That importer verified FBX dimensions, pivots and material slots, and compiled the material graphs. Packaged evidence and any remaining integration limitations belong in the game's existing STATUS and evidence records.
