# Games

Each selected game gets its own `games/<slug>/` folder with source, assets, design, build instructions, testing evidence, release preparation, and current status.

There are no selected games yet. The studio setup includes draft research examples, not a production commitment. The earlier Breakout game remains in its existing workspace as a learning reference.

Use `python scripts/studio.py status` from the repository root for the portfolio. Use `new-game` only once an idea is chosen or a prototype is authorized. See [tooling](../studio/TOOLING.md) for commands and [workflow](../studio/WORKFLOW.md) for stage checks.
